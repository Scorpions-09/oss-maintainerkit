# Code of Conduct

MaintainerKit aims to be a practical and welcoming open-source project.

Participants are expected to:

- Be respectful of different experience levels and backgrounds.
- Focus feedback on the work, not the person.
- Assume good intent while still naming problems clearly.
- Avoid harassment, insults, threats, or discriminatory language.
- Respect private security reports and sensitive project data.

Project maintainers may remove comments, issues, pull requests, or other
contributions that make the project unsafe or unproductive. Serious or repeated
violations may result in being blocked from participating.
