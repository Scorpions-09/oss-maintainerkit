# Security Policy

MaintainerKit may process issue text, pull request metadata, and commit logs.
The default CLI is local-only and does not transmit repository data.

## Reporting a vulnerability

Please report security issues privately to the project maintainer. Do not open a
public issue for suspected vulnerabilities until the report has been reviewed.

When reporting, include:

- affected version or commit
- reproduction steps
- impact assessment
- any suggested mitigation

## Security goals

- No network calls in the default runtime path.
- No credential collection.
- Clear labeling of security-sensitive triage output.
